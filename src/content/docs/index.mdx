The current release is **v2.3.1** (27 September 2026). The Linux binaries are on
the [GitHub Release](https://github.com/openpreflight/openpreflight/releases/tag/v2.3.1).
The [changelog](https://github.com/openpreflight/openpreflight/blob/v2.3.1/CHANGELOG.md)
lists the changes. The [overview](/getting-started/overview/#limits) lists the limits.
Release v1.0.0 was on 29 August 2026.
